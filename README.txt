# 🎨 Interactive Paint App (OpenCV & Python)

> Developed by [حسن نوبری |Hassan Nobari] | A simple yet interactive drawing application built with Python and OpenCV.

<br>

## 📖 Overview / معرفی پروژه
English: 
A feature-rich drawing application built from scratch using Python, OpenCV, and NumPy. This project demonstrates a strong understanding of event-driven programming, mouse callbacks, and real-time image matrix manipulation. 

فارسی:
یک برنامه نقاشی (Paint) تعاملی و کاربردی که با استفاده از پایتون، OpenCV و NumPy از صفر توسعه داده شده است. این پروژه نشان‌دهنده تسلط بر برنامه‌نویسی رویدادمحور (Event-Driven)، مدیریت توابع بازگشتی (Callbacks) و دستکاری ماتریس‌های تصویر در زمان واقعی (Real-time) است.

---

## ✨ Features / امکانات
*   🖌️ Free Drawing / رسم آزاد: Draw freely using mouse movements.
*   🎨 Dynamic RGB Colors / رنگ‌های پویا: Change brush color in real-time using trackbars.
*   📏 Adjustable Thickness / ضخامت قابل تنظیم: Modify brush thickness from 1 to 5 pixels.
*   ↩️ Undo Feature / قابلیت بازگشت: Press Z to undo the last drawn stroke (Implemented using image history stacks).
*   🗑️ Clear Canvas / پاک کردن صفحه: Press C to wipe the canvas clean.

---

## 🛠️ Tech Stack / تکنولوژی‌های استفاده شده
*   Python 3
*   OpenCV (cv2) - For image processing and GUI.
*   NumPy - For matrix operations and creating the blank canvas.
